# Security and Responsible Disclosure

CMR Lab is a personal learning environment and public engineering portfolio. The repository is not a production infrastructure template and does not grant permission to access, scan or test any live systems.

## What is published

Documentation describes selected technologies, design decisions, experiments and reusable operating methods. Sensitive administrative endpoints, credentials, access settings, key material and full live recovery procedures are intentionally excluded.

Scripts are historical learning examples. Review and adapt them to a disposable test environment before running them.

## Reporting concerns

If you notice a security concern in the repository itself, avoid posting secrets, working credentials, private URLs or exploit details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise describe only the non-sensitive nature of the concern through an appropriate private channel.

Do not attempt unauthorised testing of infrastructure associated with this project.

## Historical material

Git retains older commits, and information removed from the current branch may remain accessible in repository history or third-party copies. A content cleanup should not be mistaken for retroactive secrecy.
